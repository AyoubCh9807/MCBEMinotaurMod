## Overview

**Minotaur's Oblivion** is a custom Bedrock addon built with the official Minecraft **Script API** and written in **strict TypeScript**. It adds a handcrafted weapon with an active ability, built on the game's native item components and event system instead of command-block hacks or tick-heavy polling.

## Features

### The Golden Sword

| Ability | Description |
|---|---|
| **Golden Flame Beam** | Right-click to fire a straight beam of fire up to **20 blocks** in the direction you're looking. |
| **Piercing Damage** | Every entity along the beam takes **6 damage** and is **set on fire for 4 seconds**. Each entity is hit once per shot. |
| **Terrain Aware** | The beam stops when it hits a solid block, so it can't shoot through walls. |
| **Native Cooldown** | A **3 second** cooldown, with the built-in cooldown overlay shown on the item in the hotbar. |
| **Audio and Visual Feedback** | A particle trail along the beam's path plus a blaze-shoot sound on cast. |

## How It Works

The beam is a server-side **raycast** driven by the Script API:

1. `world.afterEvents.itemUse` detects use of the custom sword.
2. The item's `minecraft:cooldown` component is checked and started. This gives a visible cooldown bar with no tags or scoreboards needed.
3. The player's view direction and head location define the ray origin and vector.
4. The ray is stepped in 0.5 block increments. At each step it:
   - checks the block for collision, so the beam stops on solid blocks,
   - spawns a particle,
   - queries nearby entities and applies damage and fire, deduplicated with a `Set`.

### Technical Highlights

- **Strict TypeScript**, fully typed against `@minecraft/server`
- **Event-driven design** with no per-tick polling for the cooldown
- **Native item components** (`minecraft:cooldown`) instead of fragile tag workarounds
- **Configurable constants** for range, step size and damage, easy to tune
- **Clean separation** between event handling, beam logic and damage application

## Installation

### From a release

1. Download the latest `.mcaddon` from the [Releases](../../releases) page.
2. Open the file. Minecraft will import both the behavior pack and the resource pack.
3. Create or edit a world and enable both packs.
4. Enable **Beta APIs** under *Experiments* if your game version requires it.

### From source

```bash
git clone https://github.com/<your-username>/minotaur_mod.git
cd minotaur_mod
npm install
npx tsc          # compiles src/ into BP/scripts/
```

Then copy (or symlink) the `BP` and `RP` folders into your Minecraft development pack folders:

```
%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\
├── development_behavior_packs\
└── development_resource_packs\
```

Use `npx tsc -w` for watch mode while developing.

## Configuration

All tuning values live at the top of `src/main.ts`:

| Constant | Default | Meaning |
|---|---|---|
| `RANGE` | `20` | Maximum beam length in blocks |
| `STEP` | `0.5` | Distance between particle and hit checks |
| `DAMAGE` | `6` | Damage dealt to each entity hit |

The cooldown length is set in the item definition (`minecraft:cooldown` → `duration`, in seconds).
